## Pilot 信号

- 红方胜率 **41.0%**，95% CI 34.4%–47.9%，区间不包含 50%；在 200 局 pilot 中这是一个需要复测的颜色信号。
- 生死斗出现在 **71/200** 局（35.5%），共触发 **276** 次；先选方胜率 **46.0%**（95% CI 40.2%–51.9%）。
- **重复生死斗信号**：44 局触发不止一次（占生死斗局 62.0%），单局最多 **18** 次；平均每个有生死斗的局触发 **3.89** 次。触发原因分布：pieces 276。 这是明显的重复触发风险。
- 平均 **245.8** 手，中位 **248.0**；P10/P90 = 103.0/361.0。
- 平均吃子 **17.4**、将军 **10.9**、升变 **0.4**；平均分支因子 **44.4**。
- 开局：首着熵 **5.59** bit；前 4 手唯一率 **100.0%**；前 8 手唯一率 **100.0%**。
- 升变选择 **442** 次；最常用目标：坦 197 · 虎 161 · 龙 42 · 仙 42。
- 按阵营看：红方选虎 161 / 选龙 42；黑方选坦 197 / 选仙 42。双方都明显偏向“车+斜一步”的虎/坦，而不是龙/仙。
- 雪崩样本：**200** 局出现 ≥200cp 领先，领先方最终胜率 **53.0%**，翻盘率 **47.0%**；终局接近（|eval|≤300）占 **13.0%**。

## 下一轮实验建议

1. 颜色平衡：同 agent 镜像开局，扩到 2000 局；若仍偏离 45–55%，再查先手/阵营棋子价值。
2. 重复生死斗：本批有 44 局多次触发（占 62.0%），最多 18 次。做一个独立 A/B：保留当前规则 vs “同一触发条件冷却/每次材料变化只触发一次”，比较手数、胜负原因和先选方胜率；不要直接改冻结规则。
3. 生死斗先选优势暂不明显；用 1000+ 局和随机化选子复核，避免把选子 AI 的偏好当成规则优势。
4. 把 pilot 扩到 2000–5000 局，并至少加入 random / greedy / search:2 / search:3 四类 agent，避免只测一种 AI。
5. 最后必须做 5–10 人的人类试玩；AI 指标只能筛异常，不能证明“好玩”。

## 方法

- 每个游戏使用独立 seed；agent 的随机选择由同一 seed 派生。
- 搜索 agent 使用固定最大深度 + 时间上限；批量实验优先固定深度，避免纯时间限制带来的不可复现。
- 生死斗倒计时、两阶段选子、限制回合由 runner 自动处理。
- 所有对局记录在 `games.jsonl`，包含完整着法、评估、升变选择、触发原因和错误信息。
- 200 局 pilot 用于验证数据管线和发现明显异常；正式结论应基于 2000+ 局、多种 agent 和人类试玩。
