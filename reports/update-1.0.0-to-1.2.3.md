# 中国象棋WTF版：v1.0.0 → v1.2.3 更新说明

本文汇总从首个开源版本 **v1.0.0** 到当前 **v1.2.3** 的所有重要变化。  
更细的逐版本记录见 [CHANGELOG.md](../CHANGELOG.md)。

## 一句话总结

这一阶段主要做了三件事：

1. **把生死斗选子从“遮挡棋盘的全屏弹窗”改成“棋盘直接选子 + 可最小化面板”**；
2. **修改生死斗重复触发规则**：第一次之后只有虎/坦/龙/仙全部阵亡才会再次触发；
3. **加入模拟实验工具与平衡报告**，并根据反馈修正了普通 AI 的随机选着问题。

---

## 1. 规则变化

### 生死斗重复触发（v1.2.0）

第一次生死斗的触发方式不变：

- 双方 ≤5 子；
- 三次重复；
- 无进展；
- 双方同意提前进入。

第一次之后：

> **只有双方虎/坦/龙/仙全部阵亡，才会再次触发生死斗。**

以下条件不再重复触发：

- 双方 ≤5 子；
- 三次重复；
- 无进展；
- 提前同意（本来也只允许第一次）。

配套更新：

- 规则说明书升级到 **v1.1**；
- PDF 重新生成；
- 新增“虎坦龙仙均被吃”作为唯一重复触发条件的说明。

### 限制回合无合法着法（v1.2.1）

修复一个引擎边缘：

- 如果限制回合的“新子不可将死”过滤掉了所有合法着法；
- 以前会出现“无合法着法但游戏没有结果”的挂起状态；
- 现在立即按 `duelMate` 判负。

### 其他规则保持不变

- 红方先行；
- 初始为狼/勇，无兵/卒；
- 单王判负全局生效；
- 飞将、长将/长捉、三次重复、无进展保护；
- 生死斗选子、限制回合、升变逻辑。

> 由于重复生死斗规则变了，v1.0.0 的旧对局回放/模拟结果不能直接与 v1.2.3 对局按同一规则比较。

## 2. 界面与交互

### 生死斗棋盘直接选子（v1.1.0）

- 去掉遮挡棋盘的全屏选子弹窗；
- 点击棋盘上的己方棋子即可选中；
- 棋盘上显示选中序号（1/2）和目标标签（虎/坦、龙/仙）；
- 右侧选子面板显示当前棋子、目标按钮、已选列表和确认按钮；
- 面板支持**收起/展开**；
- 移动端默认收起，避免遮挡棋盘；
- 状态栏和棋盘下方同步显示“已选 N/2”。

### 其他 UI

- 选子时棋盘仍可操作；
- 目标选择有明确的选中态；
- 规则书、AI 说明、设置等原有界面保持；
- 截图和 README 已更新。

## 3. AI 变化

### 普通 AI 调强与修正（v1.2.2 → v1.2.3）

最终配置：

| 档位 | 搜索 | 时间 | 随机余量 |
|---|---|---|---|
| 简单 | depth 2 | 350ms | 90cp（保留故意犯错/随机） |
| **普通** | **depth 5** | **1400ms** | **0（不再近似同分随机）** |
| 困难 | depth 6 | 2400ms | 0 |

v1.2.2 曾把普通档设为 `depth 5 / 1400ms / randomize 8`，但实际观感反而更笨。  
原因是根节点 alpha-beta 分数是近似界，`randomize 8` 仍会把“看似接近、实际很差”的 fail-low 着法随机选中。  
v1.2.3 关闭普通档的近似同分随机，优先走搜索最佳着；简单/困难档不变。

详细记录：[ai-tuning-v1.2.3.md](ai-tuning-v1.2.3.md)。

## 4. 模拟实验工具

### 新增 simulate（v1.1.0）

- `npm run simulate`
- `npm run simulate:pilot`
- 支持 `random`、`greedy`、`search:2`、`search:3` 等 agent；
- 固定 seed、JSONL 对局记录、Markdown 报告；
- 自动处理生死斗倒计时、选子、限制回合；
- `--from` 可从已有 `games.jsonl` 重建报告；
- `--selection` / `--red-selection` / `--black-selection` 支持 natural / random / tiger / dragon 实验。

### 新增观察指标（v1.2.1）

- 先攻（红方）获胜局的首步、前 3/5 半回合、红方前 3/5 手；
- 唯一数、重复率、最高频占比、熵；
- 用于判断是否形成固定“最优开局”。

### 主要报告

- v1.0.0 旧规则基线：[pilot-001.md](pilot-001.md)
- 新重复规则 200 局：[pilot-002.md](pilot-002.md)
- 新重复规则 1000 局：[pilot-003.md](pilot-003.md)
- 旧/新规则对照：[comparison-001-002.md](comparison-001-002.md)
- Multi-agent 对照：[agent-screen.md](agent-screen.md)
- 强制升变 A/B：[selection-ab.md](selection-ab.md)
- 第二轮汇总：[round-2-results.md](round-2-results.md)
- 下一轮实验：[next-experiments.md](next-experiments.md)

### 关键结果

- 1000 局新规则：995/1000 正常结束，红方 44.0%（95% CI 41.0–47.1%）；
- 重复生死斗从旧规则 276 次/44 局多次降到 323 次/14 局多次（1000 局样本），平均 1.05 次/生死斗局；
- 先攻获胜局首步 60 种、最高频 3.4%；前 3/5 半回合几乎/完全唯一，暂未形成固定最优开局；
- multi-agent（random/greedy/search2/search3）下红方均低于 50%，黑方优势仍需继续查；
- 强制虎/坦 vs 龙/仙：同颜色约 +3.6pp，但样本小、CI 重叠，不能据此改规则。

## 5. 工具链、测试与发布

- 测试从 v1.0.0 的 39 项增加到 **41 项**；
- 新增生死斗重复规则、限制回合无合法着法、棋盘选子 UI 的测试/冒烟检查；
- `vite.config.ts` 忽略 `dist/`、`release/`、`sim/results/`、`*.zip`，避免开发服务器被构建产物锁住；
- `scripts/make-pdf.mjs` 和 `ui-smoke.mjs` 支持 `EDGE_PATH` 与多平台浏览器路径；
- 单文件构建、PDF、Windows 分享包同步更新；
- 版本标签：`v1.1.0`、`v1.2.0`、`v1.2.1`、`v1.2.2`、`v1.2.3`。

## 6. 推荐使用版本

**v1.2.3**。  
`v1.2.2` 的普通 AI 随机参数已被 v1.2.3 修正，不建议继续使用 v1.2.2 的普通档。

## 7. 兼容性提醒

- 规则已变化：旧 v1.0.0 对局不能按当前规则直接续玩；
- 项目没有存档格式；`localStorage` 只保存音效/坐标设置；
- 单文件 HTML 仍可离线运行；
- 旧版分享包/Release 仍保留历史价值，但平衡结论以 v1.2.3 报告为准。
