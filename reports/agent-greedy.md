## Pilot 信号

- 红方胜率 **33.0%**，95% CI 24.6%–42.7%，区间不包含 50%；在 100 局中这是一个需要复测的颜色信号。
- 生死斗出现在 **55/100** 局（55.0%），共触发 **59** 次；先选方胜率 **28.8%**（95% CI 18.8%–41.4%）。
- **重复生死斗信号**：4 局触发不止一次（占生死斗局 7.3%），单局最多 **2** 次；平均每个有生死斗的局触发 **1.07** 次。触发原因分布：pieces 55 · superpieces 4。 重复触发已降到较低水平。
- 平均 **65.7** 手，中位 **64.0**；P10/P90 = 43.0/83.0。
- 平均吃子 **24.9**、将军 **6.9**、升变 **0.1**；平均分支因子 **31.0**。
- 开局：首着熵 **0.99** bit；前 4 手唯一率 **2.0%**；前 8 手唯一率 **96.0%**。
- 先攻（红方）获胜局的定式观察：首步最高频占比 **51.5%**，前 3 半回合 **51.5%**，前 5 半回合 **9.1%**；**已出现定式风险**。

## 下一轮实验建议

1. 颜色平衡：同 agent 镜像开局，扩到 2000 局；若仍偏离 45–55%，再查先手/阵营棋子价值。
2. 重复生死斗已明显减少（4/55 局多次，最多 2 次）。把新规则扩到 1000–2000 局，重点确认它是否稳定接近“一局一次”，以及长局是否增加。
3. 生死斗先选优势：固定选子质量、随机化升变目标，专门跑 1000 局对比先选/后选胜率。
4. 开局重复偏高：加入 top-k 随机/开局扰动，先测“多样性上限”，再判断规则是否只有一条主线路。
5. 先攻定式风险：用强制首步/强制前 3 手 A/B，区分“AI 评估偏好”与“规则上真正的最优开局”；同时观察后手应对。
6. 把 pilot 扩到 2000–5000 局，并至少加入 random / greedy / search:2 / search:3 四类 agent，避免只测一种 AI。
7. 最后必须做 5–10 人的人类试玩；AI 指标只能筛异常，不能证明“好玩”。

## 方法

- 每个游戏使用独立 seed；agent 的随机选择由同一 seed 派生。
- 搜索 agent 使用固定最大深度 + 时间上限；批量实验优先固定深度，避免纯时间限制带来的不可复现。
- 生死斗倒计时、两阶段选子、限制回合由 runner 自动处理。
- 所有对局记录在 `games.jsonl`，包含完整着法、评估、升变选择、触发原因和错误信息。
- 100 局 pilot 用于验证数据管线和发现明显异常；正式结论应基于 2000+ 局、多种 agent 和人类试玩。
