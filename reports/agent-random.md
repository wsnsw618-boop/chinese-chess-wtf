## 下一轮实验建议

1. 先修完未结束/异常对局，再扩大样本；否则胜率会被错误样本污染。
2. 颜色平衡：同 agent 镜像开局，扩到 2000 局；若仍偏离 45–55%，再查先手/阵营棋子价值。
3. 重复生死斗：本批有 12 局多次触发（占 27.9%），最多 3 次。做一个独立 A/B：保留当前规则 vs “同一触发条件冷却/每次材料变化只触发一次”，比较手数、胜负原因和先选方胜率；不要直接改冻结规则。
4. 生死斗先选优势暂不明显；用 1000+ 局和随机化选子复核，避免把选子 AI 的偏好当成规则优势。
5. 把 pilot 扩到 2000–5000 局，并至少加入 random / greedy / search:2 / search:3 四类 agent，避免只测一种 AI。
6. 最后必须做 5–10 人的人类试玩；AI 指标只能筛异常，不能证明“好玩”。

## 方法

- 每个游戏使用独立 seed；agent 的随机选择由同一 seed 派生。
- 搜索 agent 使用固定最大深度 + 时间上限；批量实验优先固定深度，避免纯时间限制带来的不可复现。
- 生死斗倒计时、两阶段选子、限制回合由 runner 自动处理。
- 所有对局记录在 `games.jsonl`，包含完整着法、评估、升变选择、触发原因和错误信息。
- 100 局 pilot 用于验证数据管线和发现明显异常；正式结论应基于 2000+ 局、多种 agent 和人类试玩。
