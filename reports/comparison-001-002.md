# 规则 A/B：pilot-001（旧重复规则）vs pilot-002（新重复规则）

## 实验差异

- **旧规则**：第一次生死斗后，双方≤5 子、三次重复、无进展都可以再次触发生死斗。
- **新规则**：第一次之后，**只有双方虎/坦/龙/仙全部阵亡**才能再次触发；≤5 子、三次重复、无进展不再重复触发。

两份数据使用相同的：

- 200 局
- 红/黑 `search:d2:r60`
- seed `20261025`
- 最大 600 手

注意：规则改动后对局路径会分叉，所以这不是严格的同局配对 A/B；它是同配置、同 seed 的自然对照，适合看大效应，不适合证明小差异。

## 结论

### 1. 新规则确实切断了重复生死斗循环

这是本次最明确的结果：

- 触发次数 **276 → 74**
- 多次触发局 **44 → 3**
- 单局最多 **18 → 2**
- 平均每个生死斗局 **3.89 → 1.04**

第一次生死斗局数仍然是 71/200，说明新规则没有阻止第一次触发，只是阻止了“≤5 子反复重开”的循环。

### 2. 红方胜率向 50% 回归，但不能直接归因

41.0% → 45.5%，且新规则 CI 已包含 50%。
这是积极信号，但只有一种 agent、200 局，且两次对局路径分叉；需要 1000+ 局和多档 agent 复核。

### 3. 对局没有变短

平均手数 245.8 → 250.5，P90 361 → 384。
重复生死斗减少后，对局反而略长；可能是少了选子阶段的节奏重置，也可能是样本波动。需要更大样本观察。

### 4. 先选方数据仍不足以下结论

46.0% → 37.8%，但新规则只有 74 个首次选子样本，CI 27.6–49.2%，与旧规则 CI 重叠。
不建议根据这一批调整先选/后选规则。

### 5. 升变偏好仍然是虎/坦

新规则下红方 83% 选虎，黑方 90% 选坦。
重复生死斗减少后偏好没有消失，说明这更像棋子强度/AI 评估偏好，而不是重复触发造成的假象。

### 6. 先攻“最优开局定式”暂时没有出现

只统计红方获胜局：

- 旧规则：82 局，首步 42 种，重复率 48.8%，最高频占比 4.9%；
- 新规则：91 局，首步 46 种，重复率 49.5%，最高频占比 5.5%；
- 前 3 半回合、前 5 半回合的精确序列在两边都是 **100% 唯一**。

“重复率”看起来接近一半，但这是“有多少局和之前某局共享首步”的粗指标；首步有 46 种、最高频只有 5.5%，说明它**不是单一开局定式**，而是分散的多种合理首着。
前 3/5 步没有重复，更不支持“先攻最优开局已固定”。

## 下一轮建议

1. **新规则扩到 1000–2000 局**，同 agent、同 seed 扩展；确认红方 45.5% 是否稳定。
2. **加入 random / greedy / search:3 多 agent 矩阵**；当前只有 search:2。
3. **实验 C：强制虎/坦 vs 强制龙/仙**；解释虎/坦高选择率。
4. **观察手数**：如果新规则 1000 局后 P90 仍 >380，再研究无进展/长局。
5. **人类试玩**：重点看“第一次生死斗后不能重复触发”是否让残局更清晰，还是让落后方更难翻盘。
